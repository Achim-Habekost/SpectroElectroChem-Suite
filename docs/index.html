SpectroElectroChem Suite

Open-source software for the analysis, visualization and quantitative evaluation of Raman, SERS, absorption, fluorescence and rotating ring–disk electrode (RRDE) data.

Documentation and downloads

The complete user manual describes installation, CSV input formats, Raman and SERS analysis, absorpto- and fluorovoltammetry, RRDE evaluation, Levich and Koutecký–Levich analysis, signal processing, exports and reproducibility.

Open User Manual (PDF) Download editable manual (DOCX) Zenodo DOI GitHub repository

Main features

  • Raman spectrum analysis
  • Raman and SERS voltammograms
  • Absorptovoltammetry
  • Fluorovoltammetry
  • RRDE analysis
  • Levich analysis
  • Koutecký–Levich analysis
  • Tafel and Butler–Volmer analysis
  • Interactive 2D and 3D visualization
  • Excel, HTML, PNG and PDF export
