SpectroElectroChem Suite v6.0.0

Recommended Windows users should use the ready-to-run executable or installer from the GitHub release.

Python source distribution:

1. Unzip this folder completely.
2. Double-click Install_required_Python_packages.bat (normally required only once).
3. Double-click Test_Installation.bat.
4. Double-click Start_SpectroElectroChem_Suite.bat.

Important: Do not start files while they are still inside the ZIP archive.
