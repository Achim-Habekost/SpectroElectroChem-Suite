SpectroElectroChem Suite
Version 5.5.1


Open-source software for Raman, SERS, absorption, fluorescence and RRDE data analysis.

Please do the following:

1. Extract this folder completely.

2. Double-click:
   Install_required_Python_packages.bat
   (This only needs to be done once.)

3. Double-click:
   Test_Installation.bat

4. Double-click:
   Start_SpectroElectroChem_Suite.bat

IMPORTANT

Do not run any files while they are still inside the ZIP archive.
Extract the complete folder first.

Documentation:
See the User Manual (PDF or DOCX) included in the "docs" folder.
